Prototype Pollution

OWASP A03 / A08:2021 CWE-1321

1 What it is

Prototype Pollution is a JavaScript vulnerability where unsafe recursive object merging lets attacker-supplied JSON modify shared prototype properties via keys like __proto__ or constructor. Because every plain object inherits from Object.prototype, injecting a property like isAdmin: true silently alters authorization checks across the entire application.

2 The line

merge-vulnerable.js
1function deepMerge(target, source) {
2 for (const key of Object.keys(source)) {
3 const val = source[key];
4 if (val && typeof val === "object") {
5 if (!target[key]) target[key] = {};
6 deepMerge(target[key], val); ← Vulnerable Line
7 } else {
8 target[key] = val;
9 }
10 }
11 return target;
12}

Line 6 recurses directly into target["__proto__"] or target["constructor"]["prototype"], writing attacker keys onto the shared prototype inherited by all new user objects.

4 Why it matters

A single unguarded merge helper in a shared library can compromise authentication checks, feature flags, or server-side template gadgets across every object in a Node.js or browser application.

Real-world incident: Lodash CVE-2019-10744 (CVSS 9.1 Critical) allowed attackers to pollute Object.prototype via defaultsDeep using a constructor.prototype payload, impacting millions of JavaScript applications worldwide.

5 The fix

merge-fixed.js
1const BLOCKED = new Set(["__proto__", "constructor", "prototype"]);
2function deepMerge(target, source) {
3 for (const key of Object.keys(source)) {
4 if (BLOCKED.has(key)) continue; ← Security Fix
5 const val = source[key];
6 if (val && typeof val === "object") {
7 if (!Object.prototype.hasOwnProperty.call(target, key)) target[key] = {};
8 deepMerge(target[key], val);
9 } else {
10 target[key] = val;
11 }
12 }
13 return target;
14}

Explicitly blocking __proto__, constructor, and prototype stops prototype chain traversal. Switch to Fixed mode and re-run both attack payloads to verify the user stays a Standard User.
